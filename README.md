# Portfólio — Thumbnails para YouTube

Site estático (HTML + CSS + JS puro), pronto para o GitHub Pages.

## Publicar

1. Crie um repositório no GitHub (ex.: `portfolio-thumbs`) e suba todos os arquivos desta pasta na raiz.
2. No repositório: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, pasta `/ (root)` → **Save**.
3. Em 1–2 minutos o site fica no ar em `https://SEU-USUARIO.github.io/portfolio-thumbs/`.

## Antes de enviar o link

- **WhatsApp:** em `index.html`, no fim do arquivo, preencha `const WHATSAPP = '55DDDNUMERO';`.
- **Prévia do link (Instagram/WhatsApp):** em `index.html`, troque `SEU-USUARIO` e `NOME-DO-REPO` na tag `og:image` pelo endereço final.

## Trocar imagens

Substitua os arquivos em `img/` mantendo os mesmos nomes (16:9, até 1920 px de largura).
